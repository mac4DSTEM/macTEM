Notes for App Review

macEM analyses images, spectra and diffraction patterns from transmission and scanning electron microscopes, and EBSD scans of crystalline materials. You do not need data of your own to try it.

How to try it:
1. Launch the app.
2. Choose Help > Open Demo Data (Try Demo Data on the start screen holds the same items) and pick a document. Each opens in its room. The first four are generated by the app; the last three are real public datasets that ship inside the app.
3. Work down the sidebar. A room that has nothing to show for the open documents is greyed out, and its tooltip says why. The inspector is on the right; if it is hidden, choose View > Show Inspector (⌥⌘I).

With the generated TEM documents:
- Lattice Image: Image (measure a distance, change the contrast) and FFT (the transform and its spots).
- Au Diffraction Pattern: Diffraction (calibrate on the ring pattern).
- EDX Spectrum Image: EDS (elements, maps; click Quantify in the toolbar for the composition).
- EELS Spectrum Image: EELS (the thickness map is drawn on open; click Run in the toolbar to align the zero-loss peak and map it again).

With the shipped SEM datasets:
- Ni EBSD Patterns (kikuchipy) opens the Patterns room: a nickel EBSD scan. Move the pointer over the map on the left to see the pattern at each point on the right. Click Process in the toolbar to remove the backgrounds from every pattern.
- With the same document open, choose Indexing in the sidebar and click Index in the toolbar: the orientation map fills in as the patterns are indexed. Click a point on the map to pin it: the pattern pane and the tables below show its solution. In the inspector, set Method to Dictionary and click Index again to index against a nickel master pattern that ships with the app; that map also fills in as it runs, and Stop in the toolbar keeps the rows done so far.
- Maps, in the sidebar, shows the orientation map the nickel file carries. Duplex Steel Orientation Map (orix) opens a two-phase steel map in the Maps room: click Segment in the toolbar for the grains, then use the tabs under the map (Key, Grains, Pole figures, ODF, Histogram).
- SEM-EDS Spectrum (BAM TM002) opens the EDS room with one SEM spectrum.

Results, in the sidebar, lists every measurement and the SEM results in tables. The Export Report… button in its inspector writes a session report as PDF or Markdown through a save panel.

No account, sign-in, purchase or network connection is needed anywhere in the app. macEM makes no outgoing network requests.

Agent access (com.apple.security.network.server): macEM uses this entitlement for one feature. It is off by default. When the person turns it on, macEM opens a listening socket (Network.framework NWListener) on this Mac's loopback address, 127.0.0.1, port 47812. It answers incoming Model Context Protocol requests over HTTP from an AI assistant the person runs on the same Mac (for example Claude Code), so the assistant can read what macEM's windows show. The sandbox refuses the listener without this entitlement. It answers only requests that carry the token shown in that pane and refuses requests from web pages. It is not reachable from other computers. macEM makes no outgoing connections, so it has no network.client entitlement. What the assistant does with what it reads is governed by that assistant and its provider.

To see the listener:
1. Choose macEM > Settings… and open Agents.
2. Turn on the switch. Status shows "On (port 47812)".
3. Click Copy Connection Command. The copied line contains the access token.
4. In Terminal, run: curl -H "Authorization: Bearer TOKEN" http://127.0.0.1:47812/v1 (replace TOKEN with the token from the copied line). macEM answers with its name and the list of its agent tools.
Turn the switch off and the port closes.
